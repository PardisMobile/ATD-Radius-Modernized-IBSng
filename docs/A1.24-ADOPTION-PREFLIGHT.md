# A1.24 adoption preflight (read-only)

Install the project and run:

```sh
atd-radius-a124-preflight --archive /path/to/IBSng-A1.24.tar.bz2 --dsn "$ATD_DATABASE_URL" --output a124-preflight.json --fail-on-drift
```

The command is strictly read-only. It pins the canonical archive SHA-256, reads the source schema/functions/initial data/definitions from the archive, and reports missing/extra native tables and columns, explicit indexes, sequences, function names and argument signatures, baseline definition values, and core system-admin/state markers. It also inventories target-side constraint definitions, non-internal triggers, rewrite rules, and sequence configuration/current values as JSON evidence for semantic review. It can write a JSON report to a file. It does not create or alter any database object.

**A clean report is not an adoption authorization.** Column type/default/nullability normalization is conservative and may flag equivalent expressions. Constraint and trigger definitions plus sequence state are collected as target-side evidence. Trigger presence on native A1.24 tables is compared against the canonical schema (which defines none); trigger bodies on extension tables are not semantically compared. The two source-defined A1.24 deletion-protection rules are compared for presence, event, table, and normalized predicate. Canonical A1.24 stored function bodies are decoded and compared using SHA-256 digests keyed by function name and argument types. The two source-defined serial sequence ownership mappings are compared, and target-owned sequences are checked so their last_value is not behind the maximum stored value in the owned column. Primary-key, unique, foreign-key, and check-constraint signatures are now compared with canonical A1.24 DDL. Index uniqueness, method, key count, and normalized expression/predicate SQL are compared for the canonical forms supported by the source parser; this normalization is conservative and is not a general SQL-equivalence engine. Trigger bodies on extension tables are not semantically compared; plugin objects, all row data, manually managed/unowned sequence consistency, and backup/restore fidelity are also not fully verified. Do not stamp migration versions or cut over production based on this report alone. Full import/adoption requires these checks plus a verified restorable backup and a reviewed, transactional ledger-baseline procedure.


## Partial-schema failure handling — 2026-10-23

The read-only preflight now checks that every required column exists before querying the `defs`, `ibs_states`, system-admin seed, GOD permission seed, and seed-marker rows. Incomplete target tables are reported through the existing drift evidence instead of causing seed-probe SQL errors. This is a fail-closed robustness improvement only; it does not change the read-only boundary or broaden the claim of adoption completeness. Unit tests cover missing columns for each seed/marker query family.


## Native-table trigger drift — 2026-10-23

The canonical A1.24 schema files define no triggers. The preflight now flags any non-internal PostgreSQL trigger attached to a native A1.24 table as unexpected drift and includes its table, name, and server-rendered definition in the JSON report. Triggers on ATD extension tables are retained as target-side evidence and are not incorrectly treated as canonical A1.24 objects. This check is read-only and fail-closed; investigate each reported trigger before adoption.


## Sequence-definition parity — 2026-10-23

The preflight now derives the canonical A1.24 sequence settings from the source DDL: explicit unqualified sequences use PostgreSQL's default bigint bounds, while serial-generated sequences use integer bounds. It compares start, minimum, maximum, increment, cycle, and cache settings independently from live sequence high-water checks and sequence ownership. Mismatches are emitted as `inventory.sequence_definition_drift` and make `passes_audited_checks` false. A missing sequence remains reported by the existing inventory diff. This remains read-only and does not repair sequence state.

# A1.24 adoption preflight (read-only)

Install the project and run:

```sh
atd-radius-a124-preflight --archive /path/to/IBSng-A1.24.tar.bz2 --dsn "$ATD_DATABASE_URL" --output a124-preflight.json --fail-on-drift
```

The command is strictly read-only. It pins the canonical archive SHA-256, reads the source schema/functions/initial data/definitions from the archive, and reports missing/extra native tables and columns, explicit indexes, sequences, function names, baseline definition values, and core system-admin/state markers. It can write a JSON report to a file. It does not create or alter any database object.

**A clean report is not an adoption authorization.** Column type/default/nullability normalization is conservative and may flag equivalent expressions. The current audit does not compare constraint semantics, function bodies/signatures, plugin objects, all row data, sequence values, or backup/restore fidelity. Do not stamp migration versions or cut over production based on this report alone. Full import/adoption requires these checks plus a verified restorable backup and a reviewed, transactional ledger-baseline procedure.

# A1.24 AAA / RADIUS Parity Boundary

Canonical behavioral authority: `Source of Truth/IBSng-A1.24.tar.bz2`

This document is a status ledger, not a behavioral source. The canonical archive wins over any summary or test when they conflict.

## Implemented and source-traced core

- PAP, CHAP, MS-CHAPv1 and MS-CHAPv2 credential verification boundaries.
- A1.24-aligned MS-CHAP response-field consumption and MS-CHAP2-Success / AuthenticatorResponse generation.
- MPPE Send/Recv key derivation and MS-MPPE key encryption using the original Access-Request Request-Authenticator context.
- RADIUS packet codec and Access, Accounting, Disconnect and CoA packet families.
- Access-Request Message-Authenticator verification as RFC hardening; this is not claimed as legacy A1.24 behavior.
- Duplicate identity follows the source-derived tuple (source IP, source port, packet identifier, packet code).
- RFC 5176 Disconnect/CoA request authenticator encoding and response authenticator / Message-Authenticator verification.
- Shared outbound control UDP transport with endpoint checks, timeout/retry bounds and authenticated ACK/NAK handling.
- Production UDP listener wiring is opt-in; authentication and accounting packets use a per-packet PostgreSQL transaction while runtime session/RAS/IP-pool state remains process-local.
- Native accounting connection-log persistence, Start/Stop/Alive lifecycle, no_connection_log/no_commit handling and Internet charge settlement are integrated.
- Live UDP-to-PostgreSQL accounting integration and rollback atomicity have previously passed the CI integration suite.

## Implemented but partial parity

- RAS registry, provider profiles, provider session identity, provider packet context and source-traced normalization/action adapters.
- Source-traced core/SIP/SER dictionaries and provider-critical VSAs, including the exact USR vendor-429 32-bit encoding for Total Control's USR-Interface-Index.
- ChilliSpot Disconnect-Request construction and authenticated UDP client; live-device interoperability remains unverified.
- Transport-neutral request envelopes now exist for source-verified PortMaster SNMP, Total Control SNMP, PortSlave launcher and PPPD launcher operations. These builders do not execute SNMP or launcher side effects.
- Cisco's SNMP-or-RSH selection remains unresolved at the generic layer because A1.24 has two configured branches.
- Quintum Tenor's H323 disconnect cause is accounting metadata, not a generic external kill operation.

## Remaining parity work

1. Complete provider-specific request normalization and runtime integration from direct A1.24 call-path evidence.
2. Implement actual SNMP/RSH/launcher operations behind explicit, testable transport interfaces and add device/integration fixtures where available.
3. Complete the context-aware SIP/SER consumer paths and source-required dictionary gaps without overwriting core attribute meanings.
4. Complete end-to-end Access-Accept/Reject behavior across provider, credential and dictionary contexts.
5. Continue the remaining native accounting, billing, API/RBAC, migration and deployment work tracked in `ROADMAP.md`.

EAP remains an ATD extension, not an A1.24 parity requirement.

## Status discipline

- Source-traced, tested and CI-green are separate claims.
- CI-green means a completed workflow on the exact relevant commit succeeded.
- Unit/CI tests do not establish interoperability with a live RAS.
- Full A1.24 replacement parity is **not complete**; this file must not be read as a completion claim.

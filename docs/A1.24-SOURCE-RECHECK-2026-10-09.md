# A1.24 Source Recheck — 2026-10-09

## Purpose and integrity

This is a source-first recheck of recent ATD changes, not a declaration that the entire modernization project has reached source parity.

Canonical source archive: `Source of Truth/IBSng-A1.24.tar.bz2`

The reproducible workflow `.github/workflows/a1.24-source-audit.yml` checks the archive SHA-256 against `Source of Truth/README.md`, inventories all archive files, and prints direct excerpts from the original RAS provider code, PyRADIUS dictionary parser/codec, launcher, and authentication/MultiLogin anchors.

## Findings that changed code

### 1. RADIUS dictionary types

Direct source lines from `IBSng/radius_server/dictionary`:
- Line 61: `ATTRIBUTE Framed-IPX-Network 23 ipaddr`
- Line 98: `ATTRIBUTE Login-LAT-Port 63 integer`
- Lines 50, 84, 90–92, 104–105 declare the other recently adjusted attributes as integer.

The original PyRADIUS type parser defines `ipaddr` as IPv4 and `integer` as a 32-bit value. `IBSng/radius_server/pyrad/tools.py` encodes IP addresses as four octets and integers with `struct.pack("!I", value)`. Therefore the prior ATD change that moved Framed-IPX-Network to uint32 and Login-LAT-Port to string contradicted A1.24. Both are now corrected, with wire-level tests.

### 2. Enum reverse mapping

The source core dictionary defines:
- `Framed-Routing`: None=0, Broadcast=1, Listen=2, Broadcast-Listen=3.
- `Acct-Status-Type`: Start=1, Stop=2, Interim-Update=3, Alive=3, Accounting-On=7, Accounting-Off=8, and tunnel values 9–14.
- `Acct-Authentic`: RADIUS=1, Local=2.
- `NAS-Port-Type`: all values 0–19.

The original packet class first checks dictionary enum values, while `BiDict.Add` assigns `backward[value]=label`. Since `Alive=3` occurs after `Interim-Update=3`, the decoded label for wire value 3 is `Alive`. ATD now matches that reverse-map behavior and tests the source values. SIP/USR dictionary extensions remain context-sensitive and are not claimed complete.

### 3. Cisco SNMP version

The original Cisco RAS uses its configured `cisco_snmp_version` when constructing the SNMP client. The default is v2c, but the value is configurable. ATD previously hard-coded v2c in the SNMP walk and SET builders; it now accepts the source-configured v1/v2c value and passes it through the full lookup→SET service. Cisco SET OID and IF-MIB description mapping remain source-derived.

### 4. Launcher default timeout

The A1.24 launcher API defaults to a 20-second timeout. The shell-free PPPD/PortSlave transport previously defaulted to 10 seconds; its default now matches 20 seconds. The modern transport intentionally avoids shell execution and still has not been validated against the legacy script wrapper or a live RAS host.

## MS-CHAPv1/v2 and MPPE source follow-up

Direct A1.24 call sites in `core/user/plugins/password.py`, `core/user/plugins/mschap_end.py`, and `radius_server/pyrad/packet.py` confirm:
- password verification and AuthenticatorResponse use `normal_username` and `normal_password`; ATD now retrieves the canonical username when the repository exposes it;
- A1.24's `utils.str2unicode` interleaves each source byte with a zero byte before MD4. ATD now mirrors that behavior for UTF-8 database strings; ASCII RFC vectors remain unchanged. The original helper explicitly expects an ASCII string, so non-ASCII parity still depends on the source database connection charset and is not claimed fully proven;
- `MS-CHAP2-Success` contains a raw one-byte identifier followed by ASCII `S=...`. ATD now carries the identifier as bytes so values 0x80–0xff cannot expand into two UTF-8 bytes;
- A1.24 wraps `MS-CHAP-MPPE-Keys` with the RADIUS `PwCrypt` path and builds salted/encrypted `MS-MPPE-Send-Key`/`MS-MPPE-Recv-Key` attributes. The current codec has corresponding source-compatible encryption paths.

## MultiLogin follow-up

The canonical `core/user/plugins/multilogin.py` checks the configured user instance limit before checking whether `False` appears in the list of RAS MultiLogin flags accumulated across instances. ATD previously checked only the incoming RAS flag. The runtime now stores each session's source RAS capability in internal `SessionState` metadata, exposes it through active-session views, resolves the source VoIP policy branch for VoIP-only RAS types, and rejects a new login if the current or any existing active session disallows MultiLogin. The internal flag is not injected into RADIUS attributes or connection-log details. A1.24 timing parity remains bounded by the native registry's accounting-driven session creation.

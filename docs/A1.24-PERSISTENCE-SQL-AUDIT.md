# A1.24 Persistence SQL Audit

This batch corrected the persistence model against the actual A1.24 database source.

## IP pools

A1.24 does not persist used/free state in ippool_ips.

Native schema:
- ippool(ippool_id, ippool_name, ippool_comment)
- ippool_ips(ippool_id, ip)
- primary key (ippool_id, ip)

Free/used state is runtime state in IPPoolContainer; PostgreSQL stores membership only.

## Connection log

A1.24 persists connection history in connection_log and connection_log_details.

The native insertion path is the stored function insert_connection_log(bigint,numeric,timestamp,timestamp,boolean,smallint,integer,text[],text[]), which obtains connection_log_id from the connection_log_id sequence and inserts all detail name/value pairs.

## Online state

A1.24 has no online_sessions PostgreSQL table in db/tables.sql. Live online state is maintained in memory by the user/RAS runtime. Online counters are persisted separately in internet_onlines_snapshot and voip_onlines_snapshot.

ATD now has exact SQL contracts for connection history, IP-pool membership and online snapshots.

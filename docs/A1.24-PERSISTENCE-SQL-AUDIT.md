# A1.24 Persistence SQL Audit

This batch corrects the persistence model against the actual A1.24 database source.

## IP pools

A1.24 does not persist used/free state in ippool_ips.

Native schema:
- ippool(ippool_id, ippool_name, ippool_comment)
- ippool_ips(ippool_id, ip)
- primary key (ippool_id, ip)

Free/used state is runtime state in IPPoolContainer; PostgreSQL stores membership only. ATD therefore must not invent used or user_id columns in ippool_ips.

## Connection log

A1.24 persists connection history in:
- connection_log
- connection_log_details

The native insertion path is the stored function insert_connection_log(bigint,numeric,timestamp,timestamp,boolean,smallint,integer,text[],text[]), which obtains connection_log_id from the connection_log_id sequence and inserts all detail name/value pairs.

The ATD SQL contract now maps to this exact function instead of inventing a modernized insert schema.

## Online state

A1.24 has no online_sessions PostgreSQL table in db/tables.sql. Live online state is maintained in memory by the user/RAS runtime and snapshots are persisted separately (internet_onlines_snapshot, voip_onlines_snapshot, etc.).

ATD must therefore keep live-session state as a runtime service and only persist the historical/snapshot data where the A1.24 behavior requires it.

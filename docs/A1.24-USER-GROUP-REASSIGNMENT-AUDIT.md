# A1.24 User Group Reassignment Audit

Date: 2026-10-10
Canonical source: `Source of Truth/IBSng-A1.24.tar.bz2`

## Native source behavior

- `IBSng/core/user/plugins/group.py::GroupNameAttrUpdater` is a special attribute updater, not a normal row in `user_attrs`.
- `changeInit(group_name)` registers the `user/change` query handler.
- The handler resolves the group name through the native group loader and updates `users.group_id`.
- When `USER_AUDIT_LOG` is enabled, it records the change under audit attribute name `group`, with the previous and new group names.
- `user_actions.py::updateUserAttrs` runs the query, broadcasts user changes, and then invokes post-update handlers. The current ATD runtime reloads DB-backed user/RAS data per RADIUS packet; no separate in-memory group cache invalidation was identified in the inspected path.

## ATD implementation

- Added `PUT /api/v1/users/{username}/group`.
- Requires a valid administrator session and the existing source-backed `CHANGE USER ATTRIBUTES` permission with user-owner scope.
- Locks the user row, locks the target group row with PostgreSQL `FOR SHARE`, checks group access through `can_use_group`, and updates `users.group_id` (never `user_attrs`).
- Writes native user audit (when `USER_AUDIT_LOG` is enabled) and operational audit in the same transaction.
- Added repository and API tests for the native update/audit path and denied target-group access.

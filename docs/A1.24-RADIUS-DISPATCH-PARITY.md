# A1.24 RADIUS Dispatch Boundary

ATD now has one domain dispatcher covering the major protocol families required by the A1.24 runtime:

- Access-Request → AAA plugin pipeline → Access-Accept/Reject/Challenge
- Accounting-Request → typed accounting event + Accounting-Response
- Disconnect-Request → session termination
- CoA-Request → live session attribute update

The dispatcher preserves the RADIUS identifier and authenticator context on Access and Accounting responses.

The session-control adapter is registry-backed and matches sessions by Acct-Session-Id.

This is intentionally a domain/runtime boundary, not yet a production UDP listener. Packet encoding, Message-Authenticator verification, NAS client/secret lookup, replay protection, transport I/O and PostgreSQL-backed session control remain integration work.

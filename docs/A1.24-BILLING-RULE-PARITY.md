# A1.24 Billing Rule Parity Audit

Canonical source: Source of Truth/IBSng-A1.24.tar.bz2

## Implemented boundary

ATD now models the A1.24 charge-rule specificity used by `ChargeRule.__calcPriority()`:

- RAS-specific: priority 2
- port-specific: priority 1
- both: priority 3
- both wildcard: priority 0

Rules are filtered by day-of-week, time interval, RAS and port, then the highest-priority applicable rule is selected. Equal-priority rules retain loader/input order, matching the A1.24 loop which replaces the selected rule only when `rule.priority > max_priority`.

Internet pricing follows the A1.24 runtime formula:

- CPM: `cpm * seconds / 60`
- CPK: `cpk * octets / 1024`
- total = time component + transfer component

The source schema is also preserved conceptually: `charge_rules` is the parent, with `internet_charge_rules` and `voip_charge_rules` inheriting from it, while ports and days are separate child tables.

# A1.24 Attribute SQL Mapping

## Confirmed

| A1.24 table | Owner key | Attribute name | Attribute value | Evidence |
|---|---|---|---|---|
| `user_attrs` | `user_id` | `attr_name` | `attr_value` | A1.24 upgrade SQL and user loader references |
| `group_attrs` | `group_id` | `attr_name` | `attr_value` | A1.24 group loader and update handler |

The A1.24 group loader reads `group_attrs` by `group_id` and converts each row from `attr_name`/`attr_value` into the Group attribute collection. The group handler exposes explicit update and delete operations for these attributes. The user path likewise consumes attributes by name and uses them for username/password and other plugin behavior.

## Not yet enabled

`ras_attrs` is intentionally not given a guessed column contract in ATD. Its exact SQL definition must be extracted from the A1.24 `tables.sql` source or an equivalent direct source excerpt before implementation.

## Compatibility implication

The ATD SQL adapter must use the A1.24 names above. The earlier provisional `attribute/value` column names were incorrect and have been removed.

No migration is marked verified until the complete table constraints/indexes and write/delete behavior are also captured.

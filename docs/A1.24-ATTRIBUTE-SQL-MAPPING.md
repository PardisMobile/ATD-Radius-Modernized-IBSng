# A1.24 Attribute SQL Mapping

Source of truth: `IBSng-A1.24.tar.bz2` supplied for this project.

Source SHA-256: `c7117a6a2fd252aa9b8149a1ee6606f9320888da347ee4f839614bb9349d18a8`

The archive contains `IBSng/db/tables.sql`; the definitions below are now confirmed directly from that file.

## Confirmed schema

| A1.24 table | Owner key | Attribute name | Attribute value | Primary key / indexes |
|---|---|---|---|---|
| `user_attrs` | `user_id` | `attr_name` | `attr_value` | PK (`user_id`, `attr_name`); index (`attr_name`, `attr_value`); expression index for `abs_exp_date`/`first_login` |
| `group_attrs` | `group_id` | `attr_name` | `attr_value` | PK (`group_id`, `attr_name`); index (`attr_name`, `attr_value`) |
| `ras_attrs` | `ras_id` | `attr_name` | `attr_value` | PK (`ras_id`, `attr_name`); unique index (`ras_id`, `attr_name`) |

All three use `text` for both `attr_name` and `attr_value`.

## Exact source definitions

```sql
create table ras_attrs (
    ras_id integer references ras,
    attr_name text,
    attr_value text,
    primary key(ras_id, attr_name)
);

create table group_attrs (
    group_id integer references groups,
    attr_name text,
    attr_value text,
    primary key(group_id, attr_name)
);

create table user_attrs (
    user_id bigint references users,
    attr_name text,
    attr_value text,
    primary key(user_id, attr_name)
);
```

## Compatibility implications

1. An A1.24 owner can have at most one stored value for a given attribute name in each of these tables.
2. The value remains text at persistence level; interpretation/type conversion belongs to the attribute consumer/definition layer.
3. ATD must preserve the composite primary-key semantics.
4. ATD must preserve the source indexes required by lookup paths, especially attribute-name/value lookups.
5. `ras_attrs` is now confirmed and may proceed to implementation; it must not be treated as a guessed schema.
6. A migration is not `Verified` until constraints, indexes, read/update/delete behavior and consumers are tested against A1.24.

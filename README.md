# ATD Radius — Modernized IBSng

A clean modernization of IBSng A1.24: Python 3 core, PostgreSQL, RADIUS/EAP, modern PHP 8 web UI, REST API, XML-RPC compatibility, and IBSng migration tooling.

The IBSng A1.24 source is the behavioral reference. The previous Go ATD project is intentionally not copied into this repository.

See `PROJECT-SCOPE.md`, `ARCHITECTURE.md`, `ROADMAP.md`, `docs/PROJECT-CONTEXT.md`, and `ui/UI-SPEC.md`.
